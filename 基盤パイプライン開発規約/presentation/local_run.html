ローカル検証から CI へ

Local CLI

$ terraform plan -out=tfplan
$ terraform show -json tfplan > plan.json

$ conftest test --policy policies plan.json
$ checkov -d terraform --check CKV_GCP_...

$ bash scripts/bq-dry-run.sh query.sql

・PR作成前の早期フィードバック
・開発者の手元で統制を自己完結

CI Pipeline (GitHub Actions)

jobs:
  terraform-static:
    steps:
      - uses: conftest-action
      - uses: checkov-action

  sql-and-cost:
    steps:
      - run: bq-dry-run.sh

・マージ前の最終強制ゲート
・WIF によるセキュアな認証
