# データ基盤 規約・設計資料一式

**版**：v1.0

本フォルダは、GCP / BigQuery を中心とするデータ基盤の規約と、その規約に従って作成した電力小売データ分析基盤の設計書・ソースコード一式を収める。最初に本書を読み、自分の役割に応じて各文書へ進む。

## 1. 収録内容

| フォルダ | 内容 |
|---|---|
| [基盤パイプライン開発規約](基盤パイプライン開発規約/README.md) | データ基盤の規約。汎用ガイド、電力小売の個別ガイド、実装標準、設定・実行手順、CI/CDの実装サンプル、説明用スライド |
| [電力小売データ分析基盤](電力小売データ分析基盤/README.md) | 規約に従う電力小売データ分析基盤の文書一式。基本知識から運用までを工程順に並べた設計書・ソースコード |

## 2. 文書の階層と参照のルール

文書は次の3層で構成する。上の層ほど適用範囲が広く、下の層は上の層の要件を緩和してはならない。

| 層 | 文書 | 役割 |
|---|---|---|
| 第1層：汎用ガイド | [データ基盤汎用デザインガイド](基盤パイプライン開発規約/design-guides/データ基盤汎用デザインガイド.md) | 業務ドメインを問わない共通の設計標準（命名、データモデル、品質、権限、PII、コスト、CI/CD、DR/BCP、AI/ML） |
| 第2層：電力個別ガイド | [電力小売データ基盤個別デザインガイド](基盤パイプライン開発規約/design-guides/電力小売データ基盤個別デザインガイド.md) | 汎用ガイドの電力小売への適用。制度・約款・業務要件に起因する差異と代替統制 |
| 第3層：実装標準・手順・サンプル | [ローカル開発環境標準](基盤パイプライン開発規約/design-guides/ローカル開発環境標準.md) ＞ [CI/CD・Terraform自動検証チェックリストと電力小売アンチパターン集](基盤パイプライン開発規約/design-guides/CI_CD_Terraform自動検証チェックリストと電力小売アンチパターン集.md) ＞ [GitHub Actions・GCP WIF設定ガイド](基盤パイプライン開発規約/design-guides/GitHub_Actions_GCP_WIF設定ガイド.md)・[Conftest・Checkovローカル実行手順書](基盤パイプライン開発規約/design-guides/Conftest_Checkovローカル実行手順書.md) ＞ [Terraform統制ポリシー・CI/CDサンプル](基盤パイプライン開発規約/ci-policy-samples/README.md) ＞ プレゼンテーション | 規約を実装・検証するための標準、手順、コード |
| 第3層：設計書・ソースコード | [電力小売データ分析基盤](電力小売データ分析基盤/README.md)（01 基本知識 → 02 製品機能 → 03 要件定義 → 04 基本設計 → 05 詳細設計 → 06 ソースコード → 07 導入 → 08 運用） | 規約に従って構築する電力小売データ分析基盤 |

**参照のルール**

- 各文書は、自分より上位の文書だけを参照する。上位の文書は下位の文書を参照しない。第3層の2つのフォルダは互いに参照しない。
- 各文書の冒頭に「上位文書」または「上位規約」「入力」を記載し、根拠を下位から上位へたどれるようにする。
- READMEは索引であり、上記の制約の対象外とする。
- 設計書中の「汎用ガイド」「電力個別ガイド」は、第1層・第2層の文書を指す。章番号（例：汎用ガイド 2.2、電力個別ガイド 5.3）はそれぞれの文書の節番号である。

## 5. 共通の約束

| 項目 | 内容 |
|---|---|
| 版の管理 | 現時点の版はすべての文書で v1.0 とする。v1.0 には改訂履歴を持たない |
| 改訂履歴 | 今後の版の更新時に、改訂した文書の末尾（「参考資料」の後）に「改訂履歴」の表を設け、更新のたびに1行ずつ追記する。表の列は「版／改訂日／改訂内容／改訂者／承認者」とする |
| 版の採番 | 誤記の訂正や説明の補足など、要件・設計を変えない改訂は小数点以下を上げる（v1.0 → v1.1）。要件・設計・データ構造を変える改訂は整数部を上げる（v1.x → v2.0） |
| 変更の順序 | 上位から下位の順に改訂する（汎用ガイド → 電力個別ガイド → 実装標準・手順・サンプル／設計書 → ソースコード）。下位だけを直して上位と食い違わせない |
| 文書名 | 文書は日本語のファイル名とする。ソースコード、CIから参照する実装ファイル、スライドは英語のファイル名とする |
| 文字コード | すべてのテキストファイルは UTF-8（BOMなし）。ZIPで配布する場合は、ファイル名にUTF-8の印を付けて圧縮する |
| 参考資料 | 各文書の末尾に「参考資料」の見出しを置き、`* [題名](https://…)` の形式で記載する |
| ツールのバージョン | [ローカル開発環境標準](基盤パイプライン開発規約/design-guides/ローカル開発環境標準.md)に従う（Terraform 1.16.2、Python 3.13.x、Google Cloud SDK 583.0.0、Conftest 0.56.0、Checkov 3.2.301 ほか） |
