# 電力小売・発電事業 損益分析・利益階層 定義書

**版**：商用構築版（2026-09-09）
**位置づけ**：設計仕様書 `電力小売データ分析基盤.md` の計算ロジック（内部税抜統一・送電端基準統一・再エネ賦課金の税込管理・先物/PPAの差金決済）に準拠した、損益分析・BI設計の共通ドキュメント。分析チームの共通言語、および dbt 等の仕様書として使用する。
**正本との関係**：数値定義・列名は設計仕様書が正本。本書は設計仕様書の計算ロジックを「利益の階層」という分析軸で再構成したものであり、矛盾があれば設計仕様書を優先し本書を改訂する。

## 1. 損益分析の3原則

電力ビジネスの収益・粗利分析は、一般的な製造業・小売業と異なり「30分コマ単位の価格高騰リスク」と「送電損失率による電力量の目減り」を構造に内包する。以下の3原則を厳守する。

| 原則 | 内容 |
|---|---|
| ① 合成単価の禁止 | 売上・調達原価を「コミコミで1kWhあたり◯円」に丸めない。JEPX・託送・燃調・容量拠出金などの**費目別総額（円）**として個別に保持し、粗利を圧迫した真の原因を費目単位でドリルダウンできる構造にする |
| ② 電力量基準の統一（送電端換算） | 市場調達（JEPX）・相対・PPA・先物・インバランス精算はすべて送電端（系統側）基準、需要家のメーター（売上）・容量拠出金・再エネ賦課金は受電端（需要家側）基準で計量される。計画と実績の比較、BG内の原価按分、インバランス算出の前段では、需要実績量を必ず `送電端 kWh ＝ 受電端 kWh ÷ (1 − 送電損失率)` で引き直してから差分を評価する |
| ③ 再エネ賦課金の税込管理と税抜化タイミングの分離 | 賦課金は国の一意な税込公表単価であり、需要家への月次請求の計算順序は「税込のまま月合算 → 1円未満切捨て → 内税税抜化」である。コマ単位・単価単位で先に税抜化すると端数歪みで月次確定突合が不整合を起こす。日次・コマ段階では**税込総額**のまま保持・積算し、日次表示用に未丸めの**税抜換算参考値**を併記する。月次確定・請求突合の段階で初めて一括して丸め・税抜化する |

## 2. 利益の種類（5層構造）

現場の需給管理の実力（ヘッジの成否）と経営・販売サイドの実力を混同させないため、利益を5つのレイヤーに切り分けて管理する。下に行くほど固定費・販管費が差し引かれ「会社全体の利益」に近づく。

| # | 利益レイヤー | 計算定義（構成要素） | 実務上の意味・分析の急所 |
|---|---|---|---|
| ① | **コマ限界利益**（スプレッド／サヤ） | 従量料金売上 ＋ 市場売電売上<br>− JEPX市場調達原価 − JEPX従量手数料<br>− 相対・PPA調達原価 ± 先物・VPPA決済差金 | 需給管理・トレーディング部門の最重要KPI。30分コマ単位で「小売/発電価格」と「調達価格」の純粋なサヤを表す。固定費・公的費用を含まないため、価格高騰コマでヘッジ（相対・先物）が機能したかを直接評価できる |
| ② | **調整後 売上総利益**（事業粗利／ネット粗利） | ① ＋ 小売基本料金売上 ＋ FIPプレミアム（交付金）売上＋バランシングコスト（交付金）売上<br>− 託送料金（基本・従量） − 容量拠出金原価 − 非化石証書原価 | 小売・発電事業としての真の事業収益。送配電網利用料と公的制度費用という「電気を届けるために不可欠な直接原価」を差し引いた利益。JEPX定額手数料の月次調整・約款の精算丸め調整額もここに算入。**分析の主軸** |
| ③ | **売上総利益**（会計上の粗利／グロス粗利） | ② ＋ 再エネ賦課金売上（参考税抜値） − 再エネ賦課金原価（同額） | 財務諸表に乗る法定会計上の粗利。賦課金は需要家から預かって費用負担調整機関へそのまま流す（利益0円の）公的資金であり、売上・原価の双方に同額計上されるため利益の絶対額は変わらない。**社内の収益性分析では使わない**（粗利率が売上膨張で見かけ上歪むため） |
| ④ | **営業利益** | ③ − 販売費及び一般管理費（SGA） | 組織としての実力。広告宣伝費、営業インセンティブ、需給システムのライセンス料、コールセンター費、バックオフィス（CIS・請求）の償却費・人件費等の固定費を差し引いた本業の儲け |
| ⑤ | **経常利益** | ④ ＋ 営業外収益 − 営業外費用 | 財務・ファイナンスを含めた会社全体の総合力。**先物・PPAの差金決済損益は①へ原価直入する方針のため、⑤では二重に含めない**（会計上ここで初めてヘッジ損益を合算する実務もあるが、本基盤は需給実態の可視化を優先し①へ直入することを推奨） |

> ①②は本データ基盤（Gold層）が担当し、`agg_daily_pnl.contribution_margin`（①）・`gross_profit`（②）として保持する。③は賦課金を売上（`rev_levy`）と原価（`cost_levy_passthrough`）の双方に同額計上した財務諸表向けの表示で、値は②と同じ。流向横断の集計は `v_profit_layers_daily` で行う。④⑤は本基盤のスコープ外。

## 3. 需要側（小売事業：INBOUND）の費目と計算式

### 3.1 構成費目一覧

**売上（税抜統一、賦課金のみ税込保持）**

| 費目 | 意味 | 税区分 | 電力量基準 |
|---|---|---|---|
| 従量電力量料金売上 | 料金メニューの契約条件に基づく使用量課金 | 税抜 | 受電端 |
| 燃料費調整額売上 | 燃料価格変動の転嫁（固定プランのみ。市場連動プランには適用しない） | 税抜 | 受電端 |
| 再エネ賦課金売上（税込総額） | 受電端電力量 × 税込公表単価。分析上の正の値 | 税込 | 受電端 |
| 基本料金売上 | 契約電力、または過去12ヶ月の最大需要電力から動的に決定される固定売上 | 税抜 | 契約kW |

**調達原価**

| 費目 | 意味 | 税区分 | 電力量基準 |
|---|---|---|---|
| JEPXスポット調達原価 | JEPXスポット市場からの買付代金 | 税抜 | 送電端 |
| JEPX従量手数料（買） | 取引手数料＋決済代行手数料の従量課金 | 税抜 | 約定量 |
| JEPX定額手数料（暫定／確定差額） | 年会費・システム利用料等の定額固定費 | 税抜 | – |
| 相対・フィジカルPPA調達原価 | 直接契約の固定単価での引取代金 | 税抜（課税） | 送電端 |
| バーチャルPPA決済差金 | 契約単価とJEPXエリアプライスの差金のみの金融決済 | 不課税 | 送電端 |
| 先物差金決済調整額 | 電力先物の契約単価と清算値の差額（Base/Peakの商品特性に応じコマへ配分） | 不課税 | コマ割戻し |
| インバランス精算原価 | 計画と実績のズレ（送電端）に対する一般送配電事業者への精算金 | 税抜 | 送電端 |
| 託送料金（基本・従量） | 送配電網利用料。従量は高圧・特高で季節×曜日×時間帯の3次元変動 | 税抜 | 受電端／契約kW |
| 容量拠出金原価 | 将来の供給力確保のため国（OCCTO）へ支払う負担金。受電端電力量 × 年度一律単価 | 税抜 | 受電端 |
| 非化石証書原価 | 環境価値付きメニューに紐づく証書調達の引当原価（証書種別×年度単価） | 税抜 | 受電端 |

### 3.2 計算式（30分コマ粒度）

```
売上合計（税抜参考値）
  ＝ 従量電力量料金売上 ＋ 燃料費調整額売上 ＋ 基本料金（日割試算）
    ＋ 受電端需要量 × 税込賦課金単価 ÷ (1 ＋ 消費税率)     … 未丸め・税抜換算参考値

調達原価合計（税抜）
  ＝ JEPXスポット調達代金 ＋ JEPX従量手数料
    ＋ 定額手数料（暫定単価配賦）
    ＋ 相対・PPA調達原価 ＋ バーチャルPPA決済差金 ＋ 先物差金決済調整額
    ＋ インバランス精算額
    ＋ 託送従量料金 ＋ 託送基本料金（日割試算）
    ＋ 容量拠出金 ＋ 非化石証書原価

① コマ限界利益
  ＝ 従量電力量料金売上
    − ( JEPXスポット調達代金 ＋ JEPX従量手数料
        ＋ 相対・PPA調達原価 ＋ バーチャルPPA決済差金 ＋ 先物差金決済調整額 )

② 調整後 売上総利益
  ＝ 売上合計（税抜参考値） － 調達原価合計（税抜）
```

月末日行、または月次集計時に「請求書の丸めルール」を適用し、日次試算との差額を精算する。

```
月次確定売上（税抜）
  ＝ Σ従量料金 ＋ Σ燃調 ＋ 確定基本料金（実量制窓で確定） ＋ 確定再エネ賦課金（税抜）
    ※ 確定再エネ賦課金（税抜） ＝ 切捨て丸め(月間総受電端量 × 税込公表単価) ÷ (1 ＋ 消費税率)

月次確定原価（税抜）
  ＝ Σ日次原価（定額手数料除く） ＋ JEPX定額手数料（実請求額）
    ＋ 託送・インバランス・容量拠出金の実請求丸め差額

  ※ 日次合計と一送請求書の数円の丸めズレは、過去を書き換えず
    「請求丸め調整」列に月末日行として計上する
```

## 4. 発電側（電源・アグリゲーション事業：OUTBOUND）の費目と計算式

セグメント名は「発電」、メニュー種別は「FIP」または「非FIP」で管理する。

### 4.1 構成費目一覧

| 費目 | 意味 | 税区分 | 電力量基準 |
|---|---|---|---|
| 市場売電売上 | 発電実績量（送電端）× JEPXエリアプライス | 課税 | 送電端 |
| FIPプレミアム（交付金）売上 | 国（GIO）から交付されるプレミアム。実務上「FIP交付金」と呼ばれるものと同一。市場高騰で参照価格が基準価格を上回るコマは 0 円にクリップ（負の交付金にはならない） | 不課税 | 送電端 |
| バランシングコスト（交付金）売上 | 計画同時同量リスクの経過措置として国から上乗せ交付されるプレミアム（認定年度×実需給年度×電源×エリアの4軸マスタ） | 不課税 | 送電端 |
| JEPX従量手数料（売） | 売電約定電力量への課金（取引＋決済代行） | 税抜 | 約定量 |

### 4.2 計算式（FIP電源・30分コマ粒度）

```
売上合計
  ＝ 発電実績量(送電端) × JEPXエリアプライス
    ＋ 発電実績量(送電端) × P値
    ＋ 発電実績量(送電端) × 合計バランシングコスト単価

  ※ JEPXがマイナス価格のコマでは市場売電売上が負の売上（手出し）になる
  ※ P値（プレミアム単価） ＝ GREATEST(0, FIP基準価格(F値) − 市場参照価格(A値))
  ※ 月中は市場価格の発電量加重平均から算出した暫定A値、
     翌月頃のGIO公表に伴い確定A値でリラン（上書き）する

調達原価合計 ＝ 発電実績量(送電端) × JEPX従量手数料（売）

① コマ限界利益（発電側） ＝ 市場売電売上 − 調達原価合計
② 調整後 売上総利益（発電側） ＝ ① ＋ FIPプレミアム（交付金）売上 ＋ バランシングコスト（交付金）売上
```

## 5.【オプション】蓄電・揚水アセット（STORAGE）の費目と計算式

系統用蓄電池・揚水は、単一のアセットIDが「充電（需要家としての仕入れ）」と「放電（発電所としての売電）」を同時に行うため、独立したサイクル（取引単位）損益として管理する。

### 5.1 構成費目一覧

| 費目 | 意味 |
|---|---|
| 放電売上（コマ単位） | 放電量（送電端）×（放電コマのJEPXエリアプライス − JEPX売り手数料） |
| 充電原価（コマ単位） | 充電量（受電端）×（損失補正後JEPXエリアプライス ＋ 託送電力量料金 ＋ JEPX買い手数料） |
| 充放電ロス相当額 | 充電量（受電端）×（1 − マスタ公称RTE）×（損失補正後JEPXエリアプライス ＋ 託送電力量料金 ＋ JEPX買い手数料） |
| サイクル償却原価 | 設備投資額（CAPEX）÷ 想定サイクル寿命 |

### 5.2 計算式（1サイクル単位）

```
放電売上合計 ＝ Σ[放電コマ] 放電量(送電端kWh) × (JEPXエリアプライス − 従量手数料(売))

充電原価合計 ＝ Σ[充電コマ] 充電量(受電端kWh) × ( JEPXエリアプライス÷(1−送電損失率) ＋ 託送従量単価 ＋ 従量手数料(買) )

充放電ロス相当額 ＝ Σ[充電コマ] 充電量(受電端) × (1 − マスタ公称RTE) × ( JEPXエリアプライス÷(1−送電損失率) ＋ 託送従量単価 ＋ 従量手数料(買) )

サイクル損益 ＝ 放電売上合計 − 充電原価合計 − サイクル償却原価
```

**物理ロス量の評価上の注意**：日次分析で「充電量 − 放電量」をそのまま物理ロスと呼んではならない。翌日への繰越電力（SOC変動）が混ざるため、必ず次式でSOC増減分を控除した物理ロス量を算出する。

```
物理ロス量 ＝ 充電量 − 放電量 − (終了SOC − 開始SOC) × 定格容量
```

効率（RTE）はアセットマスタの公称値で固定演算し、実測値からの動的洗替は行わない（実測は監視用の参考値として別保持）。

## 6. 分析画面（BI）設計における3つの禁則

| 禁則 | 内容 | 代替策 |
|---|---|---|
| ① 粗利率（%）表示の禁止 | JEPX高騰・燃調・賦課金の変動で売上高（分母）が前月比2〜3倍に膨張することが頻繁にあり、利益の絶対額が同じでも粗利率が急落し現場の努力が正しく評価されない | 販売電力量（kWh）を分母にした**kWhあたり限界利益（円/kWh）**、または粗利絶対額を主指標に配置する |
| ② 先物・VPPA差金の営業外退避禁止 | 会計上「デリバティブ評価損益」として営業外に弾く実務があるが、需給分析ではヘッジ効果が見えなくなり経営判断を誤らせる | 先物・VPPA差金は**必ず調達原価（売上原価）の内訳に直入**し、①コマ限界利益で評価する |
| ③ 賦課金を含めた利益率分析の禁止 | 賦課金は売上・原価を同額でかさ上げし粗利率を押し下げるノイズになる | セグメント比較・メニュー別集計では、売上・原価の双方から賦課金を除外した**②調整後 売上総利益**を正としてチャートを構成する |

**部門責任の分離**：需給・トレード部門の責任は①の最大化（ヘッジによる原価のフラット化）、営業・マーケティング部門の責任は適切な値付けと④に至る販管費（SGA）の抑制。①が黒字でもSGAが過大なら④は赤字になり得るため、①と④を混同して評価しない。
